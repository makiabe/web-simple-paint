# ブラウザペイント

ブラウザ内で動作する画像編集アプリです。画像の編集処理は端末内で完結します。

https://makiabe.github.io/web-simple-paint

## 今回の修正

- キャンバスより大きな画像を原寸で貼り付け、必要な幅・高さを自動拡大。
- 表示中の画像を対象にした範囲選択、切り取り、コピー、貼り付け、移動。
- 切り取りとキャンバスの切り抜きを分離。
- Ctrl / ⌘ + X・C・V・Z、やり直しなどのショートカット。
- キャンバスサイズを含めた元に戻す・やり直す。

HTML・CSS・JavaScriptと画像素材をルートに配置し、GitHub Pagesで公開する構成です。
